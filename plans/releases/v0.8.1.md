## Release Theme

**Skill-discovery fix** — a patch on the v0.8.0 harness expansion. The bundled
planning skill was shipping `SKILL.md` files without the YAML frontmatter that
Agent Skills harnesses require, so a freshly installed skill could be silently
skipped by the very harnesses v0.8.0 added. This release makes the frontmatter
mandatory (embed + scaffold enforcement) and, alongside, tightens `aps update`
to respect the project's `cli_version` pin.

## What Ships

| Area | Detail |
| ---- | ------ |
| Skill embeds | **Frontmatter required** — bundled `SKILL.md` files carry `---` `name`/`description`; `cli/src/scaffold.rs` enforces it so a malformed embed fails fast (`ae77eac`) |
| Update safety | **Pin gate** — `aps update` gates on a `cli_version` pin mismatch rather than refreshing against a different toolchain (`967907a`, `8e6bbb6`) |
