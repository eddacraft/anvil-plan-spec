# Release Plan: v0.8.0

| Field            | Value                                        |
| ---------------- | -------------------------------------------- |
| Target           | v0.8.0                                        |
| Cut from         | `main`                                        |
| Previous release | v0.7.0 (2026-07-21)                           |
| Status           | Shipping                                      |
| Date             | 2026-07-28 (cut)                             |

## Release Theme

**Harness Expansion** — v0.7 made APS adoptable by a team; v0.8 makes it
harness-agnostic. The cut widens the supported tool set from five to twelve and
refreshes the planning assets the binary ships, so a new adopter's harness is
almost certainly already supported and the bundled skill/agents are current.

The D-045 native-discovery gate (a harness reads the `AGENTS.md` family **and**
auto-discovers the shared `.agents/skills/<name>/SKILL.md`) kept every add at
zero bespoke-asset cost, and D-039 three-way lockstep kept Rust, bash, and
PowerShell byte-parity throughout.

## What Ships

| Area | Detail |
| ---- | ------ |
| Command map | **CLI-001** — command-surface redesign map (`update`/`migrate`/`upgrade` overlaps, profile-aware surfacing); design only, no behaviour change |
| Harness cutover | **CLI-004** — D-040 finished: no user-facing Gemini scaffolding prose; Grok verified end-to-end in all three CLIs |
| Harness spike | **CLI-005** — evaluation against the native-discovery gate; **D-045** records the approved set |
| New harnesses | **CLI-006** — Antigravity, Amp, Gemini CLI, Windsurf, Roo Code, OpenClaw added to init/setup/wizard/installers, three-way parity |
| Cursor | **CLI-007** — Cursor added, reusing the `.claude/skills/` payload (zero-asset via its opportunistic scan) |
| Planning assets | **INSTALL-024** — `aps-planning` skill + `aps-planner`/`aps-librarian`/`aps-conductor` agents re-vended from the canonical eddacraft source; new **`plan-doctor`** skill bundled |

## Verification

- `cargo test` green; `test/cli-parity.sh` (bash = Rust) and the PowerShell
  parity + Native Windows journey CI legs green.
- `aps init --tools <t>` smoke-tested for every new harness in Rust and bash;
  `doctor`/`setup`/`skill_step` regression tests iterate the full tool set.
- Bundled `aps-planning` + `plan-doctor` skills byte-identical to the canonical
  eddacraft catalogue; agent bodies byte-identical to canonical.
- Each CLI-006/CLI-007 change independently verified before merge.

## Non-Goals

- Profile-aware command *behaviour* (CLI-002 — awaits the TEAM module) and the
  binary self-update surface (CLI-003) are scoped but not in this release.
- No changes to the APS markdown spec, template fields, or status vocabulary.

## Channels

Per the `release.yml` checklist: tag `v0.8.0` (builds the five targets +
`SHA256SUMS`), `cargo publish` to crates.io, and both Scoop surfaces
(`packaging/scoop/aps.json` + `eddacraft/scoop-bucket` `bucket/aps.json`) carry
the new version and the real hash from the published `SHA256SUMS`.
